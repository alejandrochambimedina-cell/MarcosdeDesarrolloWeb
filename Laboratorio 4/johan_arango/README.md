## Propósito del Proyecto
Este portal interactivo representa la entrega consolidada del APF1, construida utilizando HTML semántico, estilos propios en CSS y componentes interactivos responsivos mediante el CDN oficial de Bootstrap 5.3.8. 

## Instrucciones de Ejecución
1. Abra Visual Studio Code.
2. Inicie el servidor de desarrollo local haciendo clic derecho en `index.html` y seleccionando "Open with Live Server".
3. El proyecto se desplegará localmente en la dirección asignada por defecto (Ej: `http://127.0.0`).

## Requisitos Técnicos y Dependencias Implementadas
- Bootstrap CSS & JS Bundle: v5.3.8 (Con atributos integrity y crossorigin verificados).
- Bootstrap Icons: v1.13.1.
- JavaScript: Modo estricto (`"use strict"`), lógica de desacoplamiento de eventos y manipulación segura del DOM sin `innerHTML`.
- Accesibilidad: Enfoque automático de errores del teclado, soporte para zoom al 200% y alertas asíncronas con `aria-live="polite"`.
