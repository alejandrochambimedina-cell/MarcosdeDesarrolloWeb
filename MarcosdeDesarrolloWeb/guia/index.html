Guía de Laboratorio 1

Guía de aprendizaje de HTML, CSS y JavaScript

Introducción

En este laboratorio aprenderemos los conceptos básicos necesarios para desarrollar una página web utilizando HTML, CSS y JavaScript.

Objetivos

  • Comprender la estructura de HTML.
  • Aplicar estilos utilizando CSS.
  • Utilizar JavaScript para agregar interacción.
  • Organizar correctamente los archivos del proyecto.

HTML

HTML permite crear la estructura y el contenido de una página web.

Ejemplo:

<h1>Hola Mundo</h1>
<p>Esta es una página web.</p>

CSS

CSS permite modificar la apariencia de los elementos HTML, como colores, tamaños y posiciones.

Ejemplo:

h1 {
    color: blue;
}

JavaScript

JavaScript permite agregar interacción y comportamiento a una página web.
