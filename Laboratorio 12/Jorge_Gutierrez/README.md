# Laboratorio 12 - Jorge Gutierrez

## Proyecto TechLab

Aplicación web desarrollada con Spring Boot para la gestión de cursos y categorías.

### Tecnologías utilizadas
- Java
- Spring Boot 4.1.2
- Spring MVC
- Spring Data JPA
- MySQL 8.4
- Flyway
- Thymeleaf
- Maven

### Funcionalidades
- Gestión de cursos mediante operaciones CRUD web.
- API REST para consultar, registrar, actualizar y eliminar cursos.
- Relación entre cursos y categorías.
- Validación de datos.
- Manejo de errores y respuestas HTTP.
- Persistencia de información en MySQL.
- Migraciones de base de datos con Flyway.

### Ejecución
El código fuente se encuentra en la carpeta `demo`.

Consulta `.env.example` para conocer las variables de configuración necesarias antes de ejecutar el proyecto.
