## Descripción
Proyecto web responsivo desarrollado con HTML5 semántico, CSS3, JavaScript nativo y la integración del marco **Bootstrap 5.3.8** y **Bootstrap Icons 1.13.1**.

- Tabla de horarios responsiva con contenedor adaptable.
- Modal dinámico reutilizable con paso de variables vía `data-curso`.
- Validación accesible del formulario con JavaScript y foco automático en errores.
